# 發票記帳

用 iPhone 拍發票，家裡的 Windows 電腦自動讀取、分類、記帳。資料全部存在你自己的電腦，不會上傳到任何雲端。

- **電子發票證明聯**：讀取左右兩個 QR code，自動帶入日期、金額、品項、發票號碼，不需要 AI，又快又準。
- **自動分類**：依品項判斷（例如鮮奶茶歸「餐飲」、衛生紙歸「日用品」、汽油歸「交通」）。你改過一次，同一家店以後就會自動套用。
- **重複發票**：同一張發票拍兩次會被擋下，不會重複記帳。
- **沒有 QR code 的收據**（選用）：交給電腦上的本機 AI（Ollama）讀取，結果會標示「待確認」。
- **一張照片可以放好幾張發票**，也可以一次選多張照片上傳。
- 每月總額、分類圓餅圖、每日支出、搜尋、手動記帳、匯出 Excel 可開的 CSV。

## 安裝（只要做一次）

### 1. 安裝 Python

到 <https://www.python.org/downloads/> 下載並安裝。安裝畫面的第一頁**一定要勾選「Add python.exe to PATH」**。

### 2. 下載這個程式

在 GitHub 這個專案頁面按綠色的「Code」→「Download ZIP」，解壓縮到你想放的位置，例如 `D:\發票記帳`。

### 3. 啟動

打開 `invoice-ledger` 資料夾，雙擊 **`start.bat`**。

- 第一次會花 1 到 3 分鐘安裝需要的套件。
- Windows 防火牆跳出詢問時，勾選「**私人網路**」並按「允許」。
- 黑色視窗會顯示手機要打開的網址，例如 `http://192.168.1.20:8000`。**這個視窗要保持開著**，關掉就停止了。

### 4. 手機連上去

1. iPhone 和電腦連**同一個 Wi-Fi**。
2. 用 **Safari** 打開黑色視窗上的網址。
3. 按下方的分享鍵，選「**加入主畫面**」。之後點桌面上的「發票記帳」圖示，就像一般 App 一樣使用。

打不開的話，請到 Windows「設定 → 網路和網際網路 → 你的 Wi-Fi」，把網路設定檔改成「**私人**」。

## 出門在外也想記帳（推薦）

安裝免費的 [Tailscale](https://tailscale.com/download)：電腦和 iPhone 各裝一個，用同一個帳號登入。之後黑色視窗會多顯示一個 `http://100.x.x.x:8000` 的網址，用那個網址加入主畫面，在哪裡都連得回家，而且只有你自己的裝置能連，不會公開到網路上。

## 開機自動啟動

雙擊 `autostart-on.bat`，以後開機就會自動啟動（視窗會縮小在工作列）。不想要了就雙擊 `autostart-off.bat`。

電腦必須開著才能記帳。建議在「設定 → 系統 → 電源」把**接上電源時的睡眠**設成「永不」。

## 本機 AI 辨識（選用）

只用電子發票的話不用裝。想讓沒有 QR code 的收據也能自動讀，或讓系統自動填入店名：

1. 到 <https://ollama.com/download> 下載安裝 Ollama。
2. 開啟「命令提示字元」，執行：

   ```
   ollama pull qwen2.5vl:7b
   ```

   大約要下載 6 GB。電腦沒有獨立顯示卡、辨識很慢的話，改用比較小的模型 `ollama pull qwen2.5vl:3b`，並用記事本打開 `start.bat`，把 `qwen2.5vl:7b` 改成 `qwen2.5vl:3b`。

3. 重新啟動 `start.bat`。到 App 的「設定」頁，看到綠燈「已啟用」就完成了。

沒有裝 AI 時，第一次遇到的店家會顯示成「統編 12345678」並標示「待確認」。點進去填上店名一次，之後同一家店就會自動帶入。

## 拍照小技巧

- 讓發票下方的**兩個 QR code 清楚入鏡**，不要反光、不要太遠。
- 讀取失敗時，點開那一筆，按「重新辨識」或直接手動填金額。

## 資料與備份

所有資料都在 `invoice-ledger\data` 資料夾：`ledger.db` 是帳本，`receipts` 是發票照片。要備份就把整個 `data` 資料夾複製起來；換電腦時，把它放回新電腦的同一個位置即可。

## 開發

```
pip install -r requirements-dev.txt
python -m pytest tests
python run.py
```
